# Herrega Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Independent files may be delegated under dispatching-parallel-agents.

**Goal:** A working offline maths catch-up prototype plus 1,200 textbook-aligned scenario variations and a human translation-review pack.

**Architecture:** Pure Dart scenario catalogue feeds independent interactive boards. A Flutter shell manages goal, action, explanation and transfer stages; a versioned local progress store records independent learning. Native Android provides app-private storage through a platform channel.

**Tech Stack:** Existing Flutter/Dart project, Flutter 3.10.6, no new Dart runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-30-herrega-design.md`

## Global Constraints

- Offline Android; user will review translations/audio later.
- Exactly 1,200 deterministic scenarios; 100 per mechanic; levels 1–3.
- No exam-ready or fully translated claims; show short visual/numeric learner tasks.
- Existing cloud checkout is isolated; no Git worktree is needed or requested.
- No runtime network or new third-party Dart dependencies.

## Review Focus

- Small screens and large text must keep core actions reachable.
- Old asynchronous writes must not replace newer progress.
- Assistance must not count as independent mastery.
- Repeated callbacks/replays must not duplicate rewards.
- A changed scenario must reset all previous construction state.
