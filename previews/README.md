# Android testing preview

[Download Herrega.apk](Herrega.apk?raw=true) — Android 5.0 or later, about 20 MB.

Install it on your Android phone and tap **Jalqabi**. Watch the first banana move, then tap or drag bananas to finish the customer's order. **Itti fufi** shows what happened; **Tapha itti aanu** starts the next mission. The first rounds change one quantity at a time, then introduce matching baskets and equal picnic sharing. A written question is optional.

**Na ilaali** demonstrates with the actual objects and returns them to their previous places. The book button opens instructions. If trying a new-number question, **Furmaata** explains its solution in short steps. **Waliin** offers optional same-phone turns for friends; **Kophaa** plays solo. Harder activities keep their instruction guides and **Bu’uura shaakali** practice links. English number words and eight discovery labs remain available.

Complete a goal, close the app, and reopen it in airplane mode to check offline play and saved progress. An upgrade keeps prior progress; to see the new opening order, use its mission card if your recommended activity has already advanced.

This APK is an optimized development preview signed with the development key. The preview branch keeps the APK alongside its corresponding source so it can be downloaded without a separate file service. Translations are provisional. Full current exam coverage, science lessons and recorded audio are still pending.

Build verification: APK ZIP integrity and signature checked; SHA-256 is recorded in [Herrega.apk.sha256](Herrega.apk.sha256). Native installation and app restart still need phone testing.
